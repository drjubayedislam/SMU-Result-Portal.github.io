Admin — Create OCR index from scanned PDF

Free workflow: PDF processing happens in this browser. The PDF is not uploaded. After OCR, download results.json and manually replace data/results.json in your GitHub repository. This page has no admin login; do not leave this section exposed if that is a concern.

OCR may misread digits or rearrange table columns. Test with a non-sensitive sample first. Confirm every result against the original PDF before publishing.

Publish the OCR index on GitHub Pages

  1. Run OCR above, then tap Download results.json.
  2. Open your GitHub repository and open the data folder.
  3. Choose Add file → Upload files and upload the downloaded results.json, replacing the old file. Commit the change.
  4. Wait a minute or two, then test the student search page.

If your repository does not have a data folder, create it first. Keep the filename exactly results.json.
